# Flow Snippets

- 修订计划: ...

## 需求确认短模板 (`intent-confirmation`)

```text
🧾 需求确认
我和你确认一下，这次要做的是：
- 目标: [一句话说明用户真正要达成的结果]
- 本次会改: [预计触碰的功能 / 文件 / 行为类型；未知则写“待定位”]
- 本次不做: [明确排除项；没有则写“暂未发现额外范围”]
- 验收标准: [用户可确认的完成标准；不清楚则列“待确认”]
- 推荐模式: [FastTrack / Architect / Debug / Tester / ...]，因为 [一句话理由]

📌 下一步:
[1] 确认 - 进入需求澄清问题包；不会开始 plan / 写代码
[2] 补充 / 修正 - 调整目标、边界或验收标准
[0] 取消
```

## Brainstorm 问题包短模板 (`brainstorm-question-batch`)

```text
🧾 Brainstorm 问题包（Round N）
请一次性回复以下项目；若暂时不确定，可写“未知 / 待定 / 暂不回答”：

1. 目标:
2. 用户 / 场景:
3. 边界 / 非目标:
4. 约束:
5. 验收标准:

说明:
- 同一轮把当前阶段能确定的高信号问题一次性给全，不拆成连续的一问一答
- 若本轮回答后仍有缺口，下一轮只继续追问剩余问题，不重复已闭合项
```
